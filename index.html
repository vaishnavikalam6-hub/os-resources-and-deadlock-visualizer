ℹ️ About Project

Project Title

OS Resource Allocation and Deadlock Visualizer

Project Description

This project is a web-based educational application designed to demonstrate how an Operating System manages resources among processes and detects unsafe or deadlock conditions.

Objective

  • Understand resource allocation in Operating Systems.
  • Implement Banker's Algorithm.
  • Calculate the Need Matrix.
  • Find a safe sequence.
  • Detect unsafe/deadlock conditions.
  • Visualize process-resource relationships.

Technologies Used

HTML5 CSS3 JavaScript Banker's Algorithm Resource Allocation Graph

Project Type

Diploma / Polytechnic Operating System Microproject

📖 How to Use the Application

Step 1

Enter the number of processes and resource types.

Step 2

Click Generate Tables.

Step 3

Enter the currently available resources.

Step 4

Enter the Allocation Matrix.

Step 5

Enter the Maximum Resource Matrix.

Step 6

Click Calculate Need Matrix.

Formula:

Need = Maximum − Allocation

Step 7

Click Check Safe State to run Banker's Algorithm.

Step 8

The application displays the Safe Sequence or Deadlock/Unsafe State.
